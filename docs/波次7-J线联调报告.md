## 四、Python 侧问题清单（转 Python 专家，未改码）

1. **Qwen2.5-VL-7B-Instruct 模型不存在/无权限**（404）：C-04 点检判定全部 502（ROOM_JUDGE_MODEL_FAILED）。需修正模型 ID 或开通权限——当前点检判定只能走到降级链路。
2. **文本模型结构化输出解析失败**：初审阶段连续 `structured output invalid (attempt 1/2): ValueError: 输出中未找到 JSON 对象`（每阶段重试 2 次、约 6s/次），最终规则兜底出 PROBLEM。初审耗时被拉长（17s+），且逐项意见缺失。建议检查 prompt 的 JSON 输出约束或解析器容错。

4. **回调注册表与重试**：回调失败（400）重试耗尽后任务即悬挂（cps-rectify-6-v1、probe 的 cps-rectify-t1-v1）。建议提供回调重推接口。
5. **report_type 枚举与 Java inspectionType 语义未对齐**：Java 侧 RECTIFY/PATROL 过滤在 Python `cps-issue-inspection/room-check` 枚举下为空。需双方约定枚举映射（或 Python 兼容双枚举）。
6. **probe 污染**：联调早期探测请求（issue_id=t1/submission_id=s1 非数字字符串）在 Python 注册表残留任务 cps-rectify-t1-v1，其回调 400（Java submission_id 为数值型）。真实链路无影响，知悉即可。
