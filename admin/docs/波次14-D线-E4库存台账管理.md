## 2. 路由

App.tsx 中 `/inventory` 仍保留，向 `/admin/inventory/items` 重定向；新增三条路由：

- `/admin/inventory/items` → `InventoryItemsPage`
- `/admin/inventory/transactions` → `InventoryTransactionsPage`
- `/admin/inventory/alerts` → `InventoryAlertsPage`

左侧菜单（`AppShell.tsx`）新增三入口，标题与图标分别为：物品台账 / 出入库流水 / 库存预警。

## 3. 页面描述（文字版）

- **物品台账**：顶部 PageHead 说明 + 「新增物品」按钮；过滤卡含 编码/名称关键字、基地、库房、是否仅看低库存 4 筛选项；Table 列：物品（名称+编码+单位）、基地/库房、库存/阈值（≤ 阈值红色 Badge）、库管员、状态、编辑/停用操作；分页 Arco `Pagination`；新建/编辑 Modal 含 10 个字段（编码、名称、单位、阈值、基地、库房、库管员 2 项、所属基地编码、初始库存，库存字段编辑时禁用以强制走流水）。调 `GET /api/cps/admin/inventory-items` 与 `POST .../{id}` 同端点。
- **出入库流水**：过滤卡含 物品 ID + 类型（IN/OUT/ADJUST）；Table 列：时间、物品、类型、正负红绿颜色数量、变更前→后、操作人、备注；分页；只读，写入口合并到 Items 页登记出入库 Modal（保留既有行为，本任务只收尾页面拆分）。
- **库存预警**：过滤卡含 状态（默认 OPEN）；Table 列：物品、状态 Badge、首触时间、最近评估、评估库存/阈值、关闭信息、操作（CLOSE/IGNORE 按钮）；点击弹出 Modal，CLOSE 必填原因，IGNORE 可选说明。调 `POST /api/cps/admin/inventory-alerts/{id}/handle`。
